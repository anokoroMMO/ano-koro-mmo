# あの頃のMMO

**背中を取った者が勝つ。** 昔のネットゲームの空気をまとった、2D見下ろしの狩りゲームです（無料）。

### ▶ [ブラウザで今すぐ遊ぶ（インストール不要・PCのChrome推奨）](https://anokorommo.github.io/ano-koro-mmo/)

Windows版（ダウンロードして遊ぶ）は下の「ダウンロード」から。

ともし火の町で目を覚まし、門の東に広がる「ざわめき野」で虫や獣を狩る。
同じ野原には、同じ時間に入っている**ほかのプレイヤー**も歩いています。

📣 **公式X：[@anokoroMMO](https://x.com/anokoroMMO)** ― 版上げのお知らせはここに出します。

## ⬇ ダウンロード（Windows版）

**[最新版はこちら（Releases）](https://github.com/anokoroMMO/ano-koro-mmo/releases/latest)** から `ano-koro-mmo-<版>-windows.zip` を取ってください。

1. zip を好きな場所に展開する
2. **`あの頃のMMO.bat`** を開く（新しい版があれば自動で入れ替わります）
3. キャラ名とパスワードを決めて「作る」。次からは「入る」

- Windows が「発行元不明」「PCを保護しました」と出したら、**詳細情報 → 実行** で進めます（個人制作なので署名がありません）。
- サーバーは作者の家のPCで動いています。**サーバーが止まっている時間は入れません**（「サーバに届かない」と出たら、時間をおいて）。
- パスワードは**ほかで使っていない物**にしてください。

## 操作

| やること | 操作 |
|---|---|
| 歩く | 地面を左クリック（押しっぱなしで追いかけ続ける） |
| 向きを変える | **隣のマス**を左クリック（歩かずに、そっちを向くだけ） |
| アタック | **Space**（押しっぱなしで連打） |
| 技・薬 | **1〜0** の数字枠 |
| 持ち物 **I** ／ 技 **K** ／ 能力 **C** ／ 装備 **E** | 閉じるのは **Esc** |
| お店 | 町の「よろず屋」をクリック |

## この遊びのキモ

**攻撃しても、勝手には振り向いてくれません。** 向きは自分で変えるもの。
だから敵の横や背中に回り込めば、一方的に殴れます。

| 当たった面 | ダメージ |
|---|---|
| 正面 | 1.0倍 |
| 斜め前 | 1.2倍 |
| 側面 | 1.5倍 |
| 背面 | **2.0倍** |

この表は**あなたにも当たります**。敵に背中を見せたら大ケガ。

- **岩カブト**：硬くて、すぐこっちを向く。回り込んでもムダ。正面から殴り合え。
- **ノロ角**：一撃が痛いが、振り向くのがとても遅い。背中に回って2倍を叩き込め。
- **チョロ鼠**：弱いけど群れている。周りを一度に斬る技の出番。

倒れても町で目を覚ますだけ。持ち物は失いません。
